The browser’s service, from your shell

Same files.
Fewer clicks.

Log in, discover, connect, list and transfer. Reuse saved locations and manage archive jobs from the terminal.

JSON results fit scripts. Browser and CLI share the same policy, credentials and service; client commands do not start another server.

Complete CLI command guide
Your terminal / command guide
$ remotefs login --username YOUR_NAME
$ remotefs discover
$ remotefs connect --type rclone \
    --endpoint s3-archive

# Use the returned session id
$ remotefs ls SESSION_ID /
$ remotefs get SESSION_ID \
    /report.csv ./report.csv
$ remotefs downloads list
Build it into your own tools

Pick a folder.
Pass a descriptor.

Embed the directory picker, call the authenticated HTTP API or use the asynchronous Python SDK. Pass a location descriptor without embedding a password.

Deploy the service with systemd, launchd, Windows startup tasks or Ansible. Explicit roots, endpoints and operations define access.
