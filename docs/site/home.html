Next release / optional rclone mounts

Need a real drive?
Mount it.

Right-click an SMB share, NFS export, folder or cloud connection and choose Mount on this computer. Every app on the service host can then open, save and copy files there, with no file-size limit.

Mounts are read-write by default; untick Allow changes for read-only. Eject waits for uploads to finish. Linux and macOS are tested; Windows drives belong to your own account and are still being verified.
