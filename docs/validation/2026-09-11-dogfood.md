### Network multipart batch download

Selected two files through checkboxes on SmartNAS: `network-100MiB.bin` (104,857,600 bytes) and `notes.txt` (19 bytes). Selected ZIP, Custom, 40 MiB parts, and Start packing through the UI. The job produced three byte-split parts. A dedicated Chromium run clicked each part, confirmed repeat download, and saved each browser download on this Mac:

`af5dad64be58d4214a029ada597512a6e7cdb6bff06a96fcd47ebc52af6c531d`

The user's regular Chrome blocked the split-file download under its organisation policy. The user requested a dedicated Chromium/Playwright setup, which completed the test.
